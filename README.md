# UAE Tech Skills & Projects — Team Website

This repository contains the public team/profile website for **UAE Tech Skills & Projects**.

The initiative is a collaborative UAE-focused learning and portfolio group bringing together people from software engineering, project management, QA, business analysis, product, data, analytics, AI/ML, cloud, mobile, and engineering backgrounds.

## Current Status

The group is currently in the **domain discovery and business-problem validation stage**.

The final project domain has **not yet been selected**.

The website is designed to present:

- Who we are
- Team-member bios and skills
- Our group mission
- Our working strategy
- Current project status
- Future project deliverables
- Links to professional profiles

## Add Shahnaz's Real Photo

1. Add the photo to the `images` folder.
2. Name it `shahnaz-profile.jpg`.
3. In `index.html`, replace:

```html
images/shahnaz-profile-placeholder.svg
```

with:

```html
images/shahnaz-profile.jpg
```

A square professional photo works best.

## Publish with GitHub Pages

### Step 1 — Create a repository

On GitHub:

1. Click **New repository**.
2. Repository name suggestion:

   `uae-tech-skills-team-website`

3. Choose **Public**.
4. Click **Create repository**.

### Step 2 — Upload these files

Upload the **contents** of this folder:

- `index.html`
- `.nojekyll`
- `README.md`
- `images/`

Do not upload only the ZIP file. Extract it first and upload the files/folders inside it.

### Step 3 — Commit

Enter a commit message such as:

`Initial UAE Tech Skills team website`

Then click **Commit changes**.

### Step 4 — Enable GitHub Pages

In the repository:

1. Open **Settings**.
2. Select **Pages** from the left menu.
3. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
4. Click **Save**.

GitHub will generate the public website URL.

It normally follows this format:

```text
https://YOUR-GITHUB-USERNAME.github.io/uae-tech-skills-team-website/
```

## Updating the Website

Whenever you need to update a team bio, LinkedIn profile, role, project domain or project status:

1. Edit `index.html`.
2. Commit the change to the `main` branch.
3. GitHub Pages will update the published website automatically.

## Privacy

Before publishing personal information publicly, confirm permission from each team member for:

- Full name
- Photo
- LinkedIn profile
- Employer history
- Contact information

Do not publish WhatsApp phone numbers.
